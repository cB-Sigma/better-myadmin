## Screens / components

### 1. Insert / Edit page (`/table/change`)

**Purpose.** Render one HTML form (`#insertForm`) containing one `<table class="insertRowTable">` per row to insert or edit, followed by an actions panel, and (insert mode only) a "Continue insertion" form. Entered through the table **Insert** tab (`src/Menu.php` line 232: tab `insert`, icon `b_insrow`, route `/table/change`), the **Edit** / **Copy** per-row links in Browse (`Results.php::getUrlParams()` + `default_action=update|insert`), the **Edit**/**Copy** "With selected" buttons (`sql.ts` → `/table/change/rows` with `rows_to_delete[]` where clauses), and the `after_insert` round trips from `/table/replace`.

**Request handling (`ChangeController::__invoke`).**
1. `PageSettings->init('Edit')` renders the page-settings gear panel for the group `Edit` (`src/Config/Forms/Page/EditForm.php` → `MainForm 'Edit'` = `ProtectBinary, ShowFunctionFields, ShowFieldTypesInDataEditView, InsertRows, ForeignKeyDropdownOrder, ForeignKeyMaxLimit` plus `FeaturesForm 'Text_fields'` = `CharEditing, MinSizeForInputField, MaxSizeForInputField, CharTextareaCols, CharTextareaRows, TextareaCols, TextareaRows, LongtextDoubleTextarea`).
2. Validates `db`/`table` exist (`DbTableExists`; `hasTable` first asks `SHOW TABLES FROM `db` LIKE '<table>'`, which reads only metadata so a view with a broken definition still counts, then falls back to `SELECT 1 FROM `db`.`table` LIMIT 1` for temporary tables — the dual check restored by upstream 3e46bcca8a); on failure AJAX → JSON error "No database selected." / "No table selected.", non-AJAX → redirect to `/` with `reload=true` and message.
3. `setInsertRowsParam(insert_rows)`: if the POSTed `insert_rows` is numeric, ≥1 and differs from `$cfg['InsertRows']`, the runtime config `InsertRows` is overridden for this request (this is how "Continue insertion with N rows" reloads with N rows).
4. GET `where_clause` is only accepted if `where_clause_signature` validates via `Core::checkSqlQuerySignature()` (HMAC-SHA256 of the clause with session secret + `blowfish_secret`). Otherwise `Current::$whereClause` (set by `ChangeRowsController` for multi-row edit) is used.
5. POST `ShowFunctionFields` / `ShowFieldTypesInDataEditView` (values `'1'`/`'0'`) override the config at runtime — this implements the "Show : Function / Type" toggle links.
6. `InsertEdit::determineInsertOrEdit()`:
   - `$_POST['where_clause']` wins over the GET one.
   - If `$_SESSION['edit_next']` is set (from a previous "Edit next row" save) it becomes the where clause, is unset, and `afterInsert='edit_next'`.
   - `$_POST['after_insert']` is remembered so the dropdown stays on the user's choice.
   - **Edit mode** (where clause non-null): `analyzeWhereClauses()` runs `SELECT * FROM db.table WHERE <clause>;` per clause. An empty result prints the message "MySQL returned an empty result set (i.e. zero rows)." together with the query and continues. `foundUniqueKey` becomes true if `UniqueCondition(meta,row,forceUnique=true)->getWhereClause()` is non-empty for any row (i.e. the row has a PK or UNIQUE key).
   - **Insert mode**: `loadFirstRow()` runs `SELECT * FROM db.table LIMIT 1;` (only to obtain field metadata), and `rows = array_fill(0, $cfg['InsertRows'], [])`.
   - `default_action=insert` (Copy link / Copy selected) nulls the where clause **after** the rows are fetched, so the fetched data is shown but the save becomes an INSERT.
7. If `ChangeController::$unsavedValues` (rows that failed an input transformation in `/table/replace`) has more entries than rows, rows are extended to fit.
8. `goto` defaults to `/table/sql` (or `/database/sql` when no table). `err_url` is composed from `goto` + `db`, `sql_query`, `table`.
9. `getCommentsMap()` returns column comments only when `$cfg['ShowPropertyComments']` (default `true`); a commented column name is rendered as `<span style="border-bottom:1px dashed black" title="comment">name</span>` (`InsertEdit::getColumnTitle`).
10. Scripts loaded: `makegrid.js`, `sql.js`, `table/change.js`, `vendor/jquery/additional-methods.min.js`, `gis_data_editor.js`, plus any `getScripts()` from input transformation plugins encountered (`InsertEdit::$pluginScripts`).
11. If `Current::$displayMessage` is set (coming back from `/table/replace` with `same_insert`/`new_insert`/`edit_next`) it is displayed above the form together with the executed query.
12. `getForeigners(db, table)` loads both internal relations (pmadb `pma__relation`) and native FOREIGN KEYs.

**Layout top-to-bottom.**
1. Page-settings panel (gear) for group `Edit`.
2. Optional message block (result of previous save).
3. `<form id="insertForm" class="lock-page[ disableAjax]" method="post" action="/table/replace" name="insertForm"[ enctype="multipart/form-data"]>` (`get_html_for_insert_edit_form_header.twig`). `enctype` multipart iff PHP `file_uploads` is on (`Config::isUploadEnabled()`); `disableAjax` iff the table has a BLOB column **and** upload is enabled (file uploads cannot go through the AJAX page loader). `lock-page` enables the unsaved-changes guard (`functions.ts::onloadLockPage` hashes each input's initial value; leaving prompts `strConfirmNavigation`).
4. Hidden inputs from `getFormParametersForInsertForm()`: `db`, `table`, `goto`, `err_url`, `sql_query` (from POST, or from GET if `sql_signature` validates), `where_clause[<keyId>]` (trimmed) for each edited row, `clause_is_unique` (0/1, from POST or GET).
5. Toggle links: if either `ShowFunctionFields` or `ShowFieldTypesInDataEditView` is off, the literal "Show" followed by ` : <a>Function</a>` and/or ` : <a>Type</a>` (`InsertEdit::showTypeOrFunction($which, $urlParams, false)`). Each link POSTs back to `/table/change` with the directive set to `1` and the other directive at its current value, plus `goto=/sql`. When a column is shown, its `<th>` header text is itself a link with title "Hide" that POSTs the directive as `0`. The controller comment notes this "currently does not work for multi-edits".
6. For each row `rowId` (0-based):
   - In insert mode and `rowId > 0`: `<input type="checkbox" checked name="insert_ignore_<rowId>" id="insert_ignore_<rowId>"><label>Ignore</label><br>` (`getHtmlForIgnoreOption`). Pre-checked, meaning the extra rows are skipped unless the user types into them (JS unchecks it on any field change). Rows repopulated from `$unsavedValues` are rendered unchecked.
   - One `<div class="table-responsive-lg"><table class="table table-striped align-middle my-3 insertRowTable w-auto">` (`get_head_and_foot_of_insert_row_table.twig`): `<thead>` row 1 = a right-aligned "Go" submit button spanning 5 cols; row 2 = headers **Column**, [**Type**], [**Function**], **Null**, **Value** (Value `<th class="w-50">`); `<tfoot>` repeats the "Go" button row; then `<tbody>` with one `<tr class="noclick">` per column (`column_row.twig`). Generated/virtual columns (`extra` in `VIRTUAL, PERSISTENT, VIRTUAL GENERATED, STORED GENERATED`) are skipped entirely (`getHtmlForInsertEditRow`).
   - After the table: `<br><div class="clearfloat"></div>`.
7. Actions panel (`actions_panel.twig`, `<fieldset id="actions_panel">` inside a card) — see §1.4.
8. `</form>`.
9. GIS editor modal shell (`modals/gis_editor.twig` with `location=change`, `id="gisEditorModal"`, `modal-xl`, `data-bs-backdrop="static"`, body `#gis_editor`).
10. Insert mode only: "Continue insertion" form (`continue_insertion_form.twig`) — see §1.5.

#### 1.1 Column row cells (`column_row.twig`)

Cell A — **Column**: `field_title` (escaped name, dashed-underlined with tooltip if commented) and `<input type="hidden" name="fields_name[multi_edit][<rowId>][<md5>]" value="<field>">`. All per-field input names use `[multi_edit][<rowId>][<md5(fieldname)>]` (`InsertEdit::$columnNameAppendix`; MD5 is used "to avoid having special characters in the name attribute", bug #1746964).

Cell B — **Type** (only if `ShowFieldTypesInDataEditView`, default `true`): `<span class="column_type" dir="ltr">displayType</span>`; `displayType` is `set`/`enum` for those types (values hidden) else the full type with any ` /* comment */` stripped (`InsertEditColumn::getDisplayType`). `text-nowrap` unless set/enum.

Cell C — **Function** (only if `ShowFunctionFields`, default `true`):
- If `isColumnBinary()` → the literal text **Binary**. `isColumnBinary` is true when (`ProtectBinary='blob'` and column is BLOB and upload not enabled) or (`ProtectBinary='all'` and column is BINARY/VARBINARY) or (`ProtectBinary='noblob'` and column is BINARY/VARBINARY).
- Else if ENUM or SET → literal `--`.
- Else `<select name="funcs[multi_edit][r][md5]" id="field_<idx>_1" onchange="return verificationsAfterFieldChange(md5, r, trueType)">` with options from `Generator::getFunctionsForField()`: first an empty `<option></option>`, then **every** function from `Types::getAllFunctions()` (the sorted union of the CHAR, NUMBER, DATE and SPATIAL lists — the dropdown is *not* filtered by column type), the default one `selected` unless the column has a foreign key (`hasForeignField`), and finally `<option value="PHP_PASSWORD_HASH" title="The PHP function password_hash() with default options.">password_hash() PHP function</option>`.

Function lists (`Types::getFunctionsClass`):
- CHAR: `AES_DECRYPT, AES_ENCRYPT, BIN, CHAR, COMPRESS, CURRENT_USER, DATABASE, DAYNAME, DES_DECRYPT, DES_ENCRYPT, ENCRYPT, HEX, INET6_NTOA, INET_NTOA, LOAD_FILE, LOWER, LTRIM, MD5, MONTHNAME, OLD_PASSWORD, PASSWORD, QUOTE, REVERSE, RTRIM, SHA1, SHA2, SOUNDEX, SPACE, TRIM, UNCOMPRESS, UNHEX, UPPER, USER, UUID, UUID_v4, UUID_v7, VERSION` — `INET6_NTOA` removed when (MariaDB < 10.0.12) or server < 5.6.3; `UUID_v4`/`UUID_v7` kept only for MariaDB ≥ 11.7.0.
- DATE: `CURRENT_DATE, CURRENT_TIME, DATE, FROM_DAYS, FROM_UNIXTIME, LAST_DAY, NOW, SEC_TO_TIME, SYSDATE, TIME, TIMESTAMP, UTC_DATE, UTC_TIME, UTC_TIMESTAMP, YEAR`.
- NUMBER: `ABS, ACOS, ASCII, ASIN, ATAN, BIT_LENGTH, BIT_COUNT, CEILING, CHAR_LENGTH, CONNECTION_ID, COS, COT, CRC32, DAYOFMONTH, DAYOFWEEK, DAYOFYEAR, DEGREES, EXP, FLOOR, HOUR, INET6_ATON, INET_ATON, LENGTH, LN, LOG, LOG2, LOG10, MICROSECOND, MINUTE, MONTH, OCT, ORD, PI, QUARTER, RADIANS, RAND, ROUND, SECOND, SIGN, SIN, SQRT, TAN, TO_DAYS, TO_SECONDS, TIME_TO_SEC, UNCOMPRESSED_LENGTH, UNIX_TIMESTAMP, UUID_SHORT, WEEK, WEEKDAY, WEEKOFYEAR, YEARWEEK` (same `INET6_ATON` version rule).
- SPATIAL (server ≥ 5.6): `ST_GeomFromText, ST_GeomFromWKB, ST_GeomCollFromText, ST_LineFromText, ST_MLineFromText, ST_PointFromText, ST_MPointFromText, ST_PolyFromText, ST_MPolyFromText, ST_GeomCollFromWKB, ST_LineFromWKB, ST_MLineFromWKB, ST_PointFromWKB, ST_MPointFromWKB, ST_PolyFromWKB, ST_MPolyFromWKB`; older servers get the same names without `ST_`.

Default function selection (`Generator::getDefaultFunctionForField`):
- `uuid` type → none.
- Otherwise `$cfg['DefaultFunctions']['FUNC_<CLASS>']` where class comes from `Types::getTypeClass()` (NUMBER for `TINYINT,SMALLINT,MEDIUMINT,INT,BIGINT,DECIMAL,FLOAT,DOUBLE,REAL,BIT,BOOLEAN,SERIAL`; DATE for `DATE,DATETIME,TIMESTAMP,TIME,YEAR`; CHAR for `CHAR,VARCHAR,TINYTEXT,TEXT,MEDIUMTEXT,LONGTEXT,BINARY,VARBINARY,TINYBLOB,MEDIUMBLOB,BLOB,LONGBLOB,ENUM,SET,INET4,INET6`; SPATIAL for the 8 geometry types; JSON; UUID). Defaults: `FUNC_CHAR=''`, `FUNC_DATE=''`, `FUNC_NUMBER=''`, `FUNC_SPATIAL='GeomFromText'`, `FUNC_UUID='UUID'`, `first_timestamp='NOW'`. For SPATIAL on server ≥ 5.6 the configured name gets `ST_` prefixed if missing so that it matches an option.
- TIMESTAMP columns with no default, not `on update CURRENT_TIMESTAMP`, NOT NULL → `DefaultFunctions['first_timestamp']` (`NOW`). This also applies when editing: saving the row unchanged then sends `NOW('<stored value>')`, which MySQL rejects, unless the user clears the function. (`firstTimestamp` is simply `trueType === 'timestamp'` — the source notes the "first" tracking is vestigial, so this applies to every such timestamp column.)
- Insert mode only, PRIMARY key of exact type `char(36)` or `varchar(36)` → `DefaultFunctions['FUNC_UUID']` (`UUID`).

Cell D — **Null**: only rendered with content when the column is nullable (`column.isNull`): `<input type="hidden" name="fields_null_prev[...]"[ value="on"]>` (value `on` iff the current value is really NULL and the column is not a timestamp), `<input type="checkbox" class="checkbox_null" name="fields_null[...]" id="field_<idx>_2" aria-label="Use the NULL value for this column."[ checked]>`, plus hidden helpers `nullify_code` (see §1.3), `hashed_field` (md5), `multi_edit` (`[multi_edit][r]`).

Cell E — **Value** `<td data-type="<trueType>" data-decimals="<fsp>">` (`decimals` = fractional-seconds precision parsed from `timestamp(6)`/`datetime(3)`/`time(n)`, else 0). First child: `<span class="default_value hide">special_chars</span>` — the formatted default/current value, read by `change.ts` when cloning rows for "Continue insertion". Then the widget, chosen in this order (`column_row.twig`):

1. **Input transformation present** (`columnMime['input_transformation']`, plugin is an `IOTransformationsPlugin`) → `transformed_value` HTML from `plugin->getInputHtml(columnNameAppendix, options, currentValue, fieldIndex)` replaces the whole widget (options get `wrapper_link`/`wrapper_params` = `db, table, transform_key, where_clause_sign, where_clause`).
2. **Foreign-key, link mode** (`foreignData->foreignLink`, i.e. foreign table has ≥ `ForeignKeyMaxLimit` rows or the dropdown query returned nothing): backup field + `<input type="hidden" name="fields_type[...]" value="foreign">` + `<input type="text" name="fields[...]" class="textfield" tabindex id="field_<idx>_3" value="<data>">` + `<a class="ajax browse_foreign" href="/browse-foreigners" data-post="db,table,field,rownumber=<rowId>,data">` with icon `b_browse` "Browse foreign values".
3. **Foreign-key dropdown** (`foreign_dropdown` non-empty): backup field + hidden `fields_type` = `hex` if column is BINARY/VARBINARY else `foreign` + `<select name="fields[...]" class="textfield">` with options from `Relation::foreignDropdown()` (see §3).
4. **Textarea** for `longtext` when `LongtextDoubleTextarea` (default `true`), or any type containing `json` or `text` (tinytext, text, mediumtext, longtext): backup field + `<textarea name="fields[...]" id="field_<idx>_3" data-type=<TypeClass> dir=<text dir> rows cols tabindex [data-maxlength][class="charField"]>`. Rows/cols = `TextareaRows` (15) × `TextareaCols` (40); doubled for longtext when `LongtextDoubleTextarea`; for CHAR types `max(CharTextareaRows, 7)` × `CharTextareaCols` (40) and `data-maxlength` = the bracket spec. A leading `\r\n` in the value is prefixed with an extra `\n` ("We need to duplicate the first \n or otherwise we will lose the first newline"). If a `text` value is longer than 32000 chars an extra `<td>` appears: "Because of its length, this column might not be editable."
5. **ENUM**: backup field + hidden `fields_type=enum`; if the full column type string is longer than 20 characters → `<select class="textfield">` with a leading empty option then one option per value (selected = `enum_selected_value`); else one `<input type="radio" class="textfield" id="field_<idx>_3_<i>">` + `<label>` per value. `enum_selected_value` is the value equal to the current data, or (when data is empty and (not editing or column NOT NULL)) the value equal to the column default.
6. **SET**: backup field + hidden `fields_type=set` + `<select name="fields[...][]" multiple size="min(4, count)" class="textfield">`, options selected when present in `data` split on `,`.
7. **BINARY/VARBINARY/BLOB family**:
   - Protected (`ProtectBinary='blob'` and BLOB, or `'all'`, or `'noblob'` and not BLOB): text "Binary - do not edit (<size> <unit>)" (size via `Util::formatByteDown(strlen, 3, 1)`), hidden `fields[...]=""` and hidden `fields_type=protected`.
   - BLOB, or column length > `LimitChars` (50): backup + hidden `fields_type=hex` + `<textarea data-type="HEX">` (value is hex of the bytes; see `getDefaultValueAndBackupFieldForExistingRow`).
   - Otherwise: backup + hidden `fields_type=hex` + `<input type="text" data-type="HEX" size="<hexInputSize>">` where `hexInputSize = min(max(length*2, 4), LimitChars)`.
   - If uploads are enabled and column is BLOB: `<br><input type="file" name="fields_upload[...]" class="textfield noDragDrop" size="10">` followed by "(Max: <size>)" from `getMaxUploadSize()` = min(PHP `upload_max_filesize`/`post_max_size`, type cap: tinyblob 256, blob 65536, mediumblob 16777216, longblob 4294967296).
   - If `$cfg['UploadDir']` (default `''`) is non-empty: `getSelectOptionForUpload()` renders `<br><i>Or</i> web server upload directory:<br><select name="fields_uploadlocal[...]"><option value="" selected></option>…files…</select>` listing regular, non-symlink files of `Util::userDir(user, UploadDir)` (`%u` replaced by the username; `FileListing::getDirContent`). Unreachable dir → red "Error" + "The directory you set for upload work cannot be reached."; empty dir → nothing.
8. **Geometry types** (`geometry, point, linestring, polygon, multipoint, multilinestring, multipolygon, geometrycollection`): the generic text input (`value`) followed by `<button type="button" class="btn btn-link open_gis_editor" data-bs-toggle="modal" data-bs-target="#gisEditorModal" data-row-id="<rowId>">` with icon `b_edit` "Edit/Insert". Geometry columns report length -1 → forced to 30 (`InsertEditColumn`).
9. **Everything else** → `getValueColumnForOtherDatatypes()` rendering `value_column_for_other_datatype.twig`.

#### 1.2 Generic value widget (`value_column_for_other_datatype.twig`, `InsertEdit::getValueColumnForOtherDatatypes/getTextarea/getColumnSize/getIntegerRange`)

- CHAR/VARCHAR become a **textarea** (`getTextarea`, class `charField`, `CharTextareaRows`(7) × `CharTextareaCols`(40), `data-maxlength`=spec) when `$cfg['CharEditing']==='textarea'` (default `'input'`) **or** the current value contains a newline **or** the declared length exceeds `MaxSizeForInputField` (60) — in the last case `getColumnSize()` flips the runtime `CharEditing` to `textarea` (and `getValueColumnForOtherDatatypes` resets it to the original after rendering).
- Otherwise `<input type="text" name="fields[...]" value size="<fieldsize>" [data-maxlength=size for char] [min max for integers] data-type="INT|<TypeClass>" class="textfield[ datefield| timefield| datetimefield]" onchange="verificationsAfterFieldChange(...)" tabindex [inputmode="numeric"] id="field_<idx>_3">`.
  - `fieldsize`: for CHAR = bracket length, otherwise the result-set field length (`float|double` forced to 100); then clamped to `[MinSizeForInputField (4), MaxSizeForInputField (60)]`.
  - Note: `trueType` keeps trailing attributes, so on MySQL ≥ 8.0.19 (which reports `int unsigned` without a display width) unsigned integers get neither the range nor `data-type="INT"` (the class is empty).
  - Integer types (`Types::getIntegerTypes`) get `min`/`max` from `Types::getIntegerRange(type, signed)` honoring `unsigned` in the spec, `data-type="INT"` and `inputmode="numeric"`.
  - Class `datefield` for `date`, `timefield` for `time`, `datetimefield` for `datetime`/`timestamp` — these receive the jQuery UI date/time picker.
- Hidden companions emitted in the same cell: `virtual[...]=1` when `extra` matches `/(VIRTUAL|PERSISTENT|GENERATED)/` and does not contain `DEFAULT_GENERATED`; `auto_increment[...]=1` when `extra == 'auto_increment'`; `fields_type[...]=<trueType>` for `bit`, `uuid`, `timestamp`, `datetime`, `date` (the server uses this type tag in `formatAsSqlValueBasedOnType`).

**Value population.**
- *Editing* (`getDefaultValueAndBackupFieldForExistingRow`): NULL → `realNullValue=true`, empty value. `bit` → `Util::printableBitValue(int, length)` (binary string). `timestamp/datetime/time` containing `.` → `Util::addMicroseconds()` (pads to 6 fractional digits). Geometry → `Gis::convertToWellKnownText(value, includeSRID=true)` which runs `SELECT ST_ASTEXT(x'hex'[, 'axis-order=long-lat']), ST_SRID(x'hex')` and yields `'WKT',srid`. BINARY/VARBINARY, and BLOB unless `ProtectBinary='all'` → `bin2hex`. Copy (`default_action=insert`) of a PRI `auto_increment` column → emptied "to prevent duplicate key error". A hidden `<input type="hidden" name="fields_prev[...]" value="<current>">` ("backup field") is always emitted so the server can detect unchanged values.
- *Inserting* (`getDefaultValue`): the column DEFAULT (or the repopulated unsaved value); `bit` defaults `b'101'` → `101` (`Util::convertBitDefaultValue`); `timestamp/datetime/time` → `addMicroseconds` (leaves `CURRENT_TIMESTAMP[(n)]` untouched); `binary/varbinary` → `bin2hex`. A NOT NULL `datetime` without default in insert mode is pre-filled with the current server time `date('Y-m-d H:i:s')` (`InsertEditColumn::__construct`). `realNullValue` is true when the default is NULL (so the NULL checkbox is pre-checked for nullable columns without a default).
- Repopulation: when `ChangeController::$unsavedValues[rowId]` exists, values are used as-is (`$asIs=true`, no hex/WKT conversion).

#### 1.3 Client-side behaviours (`resources/js/table/change.ts`)

- **`verificationsAfterFieldChange(md5, rowId, type)`** (the `onchange` of every value input and function select):
  - If the changed element is the function select and the value is one of `AES_ENCRYPT, AES_DECRYPT, DES_ENCRYPT, DES_DECRYPT, ENCRYPT, SHA2` → appends `<br><input type=text name="salt[multi_edit][r][md5]" id="salt_<id>" placeholder="Encryption key">` after the value input; any other function removes it.
  - `MD5` adds validator `validationFunctionForMd5` (fails when the column's `data-maxlength` < 32); `DES_ENCRYPT`/`AES_ENCRYPT` add `validationFunctionForAesDesEncrypt` (passes only for `HEX`/`CHAR` data-types).
  - `HEX` on an `int*` column shows `<p id="note<id>">` with `HexConversionInfo` = "The HEX function will treat the integer as a string while calculating the hexadecimal value".
  - Always unchecks the row's NULL checkbox for this field and unchecks `insert_ignore_<rowId>`.
  - When a function is selected: `min`/`max` attributes are removed; for `NOW` they are set to `0..data-decimals` (NOW(fsp) argument).
  - When no function is selected and rules not yet added: `date*/time*` → `validationFunctionForDateTime`; `data-type=INT` → `validationFunctionForInt` + `min`/`max` (from `data-min`/`data-max`); `data-type=CHAR` → `maxlength` rule (`data-maxlength`; if ≤4 it uses the digit inside `char(n)`/`varchar(n)`); `data-type=HEX` → `validationFunctionForHex` (`/^[a-f0-9]*$/i`). All rules `depends` on the row's Ignore checkbox being unchecked (`checkForCheckbox`). Selecting a function later removes all rules and error markup.
- **Validators registered on load** (jQuery Validation): `validationFunctionForInt` = `/^([+-]|0x)?([0-9]*\.?[0-9]+|[0-9]+\.?[0-9]*)([eE][+-]?[0-9]+)?$/i` (message `strEnterValidNumber` "Please enter a valid number!"); `validationFunctionForHex`; `validationFunctionForMd5`; `validationFunctionForAesDesEncrypt`; `validationFunctionForDateTime` → `isDate()` (accepts `YYYY-M-D`, 2-digit years, separators `. * ^ + / @` normalised to `-`, month/day tables, Feb leap check; for `timestamp` year must be 1978..2038 with the Jan-19-2038 cut) / `isTime()` (`-?[0-838]:MM:SS[.ffffff]`); for datetime/timestamp the literals `CURRENT_TIMESTAMP`, `current_timestamp()` and `0000-00-00 00:00:00` pass, a date-only value passes. Messages come from `validator-messages.ts` (`strValidationFunctionForDateTime`, `…Hex`, `…Md5`, `…AesDesEncrypt`, `strValidatorMaxLength`, etc.).
- **`nullify(code, md5, multiEdit)`** on NULL-checkbox click: resets the function select (`selectedIndex=-1`), then per `nullify_code`: `1` ENUM select (type string > 20 chars) → `selectedIndex=-1`; `2` ENUM radios → all unchecked; `3` SET → `selectedIndex=-1`; `4` FK dropdown → `selectedIndex=-1`; `6` FK text with browse link → value `''`; `5` everything else → value `''`. (`getNullifyCodeForNullColumn`.) There is no automatic re-check of NULL when the input is later emptied on this form (that behaviour exists only in grid editing, `makegrid.ts`).
- **Date/time pickers** (`functions.ts::addDateTimePicker/addDatepicker`, translations in `datetimepicker.ts`): jQuery UI datepicker + timepicker addon on `.datefield/.timefield/.datetimefield`, triggered by a calendar button (`b_calendar.png`), `dateFormat 'yy-mm-dd'`, time format `HH:mm:ss` plus `.l` (millis) when `data-decimals` 1–3 or `.lc` (micros) when > 3, `hourMax` 99 for `time`, `firstDay` from `$cfg['FirstDayOfCalendar']`, `changeYear`, `constrainInput:false`, hover tooltips "MySQL accepts additional values not selectable by the slider/datepicker; key in those values directly if desired".
- **`submit_type` change**: when switching to `insert`/`insertignore`/`showinsert` in edit mode, every `auto_increment` column's value is blanked; switching back to `save` restores `fields_prev`.
- **GIS copy button** (`button.gis-copy-data`): unchecks NULL and the row's Ignore checkbox for the target input.
- **Ignore checkbox click** triggers `$('#insertForm').valid()`.
- **Keyboard navigation**: `keyhandler.ts` binds `keydown/keyup` on `table.insertRowTable`: with Ctrl held, Arrow Up/Down/Left/Right moves focus between elements whose ids follow `field_<row>_<col>` (col 1 = function select, 2 = NULL checkbox, 3 = value; for radios `field_r_3_0`), selecting the text in non-select targets. The actions panel shows the hint "Use TAB key to move from value to value, or CTRL+arrows to move anywhere." Tab order is `tabindex = rowOffset*columnCount + columnNumber + 1` on value widgets (recomputed by JS after cloning rows; `.control_at_footer` controls get the trailing indexes).
- **Preview SQL** (`.preview_sql` button → `functions.ts::previewSql`): POSTs the form plus `do_save_data=1&preview_sql=1&ajax_request=1` to `/table/replace`; the response `sql_data` (rendered `components/_preview_sql.twig`: each statement via `format_sql`, or "No change") is shown in `#previewSqlModal` with syntax highlighting.
- **Page lock**: because the form has class `lock-page`, AJAX navigation away with modified fields asks `strConfirmNavigation`; "Continue insertion" decrease checks `AJAX.lockedTargets` to decide whether to confirm.

#### 1.6 Server-side save (`/table/replace`, `ReplaceController` + `InsertEdit`)

Preconditions: `db`, `table`, `goto` must be present (else `missingParameterError`).

`after_insert` handling: for `new_insert|same_insert|edit_next` the value is copied into the URL params; for `same_insert` each `where_clause[]` is re-added so `/table/change` reopens the same rows; for `edit_next` `setSessionForEditNext()` runs `SELECT * FROM db.tbl WHERE <clause with "` =" replaced by "` >"> LIMIT 1;` and stores `UniqueCondition(...,forceUnique)->getWhereClause()` in `$_SESSION['edit_next']`.

`getGotoInclude()`: if `after_insert` is one of the three → `/table/change`; else based on `goto` (`index.php?route=/sql` → `/sql`; `/database/sql` resets the current table) else `/table/sql` or `/database/sql`.

`getParamsForUpdateOrInsert()`: with `where_clause` present → `loopArray` = the clause(s), `usingKey=true`, `isInsert = submit_type ∈ {insert, showinsert, insertignore}`; without → `loopArray = array_keys(fields[multi_edit])`, `usingKey=false`, `isInsert=true`. `insertignore` ⇒ `INSERT IGNORE`.

Per row: skipped if (inserting without key) `insert_ignore_<row>` is posted. Column arrays read from `fields`, `fields_name`, `fields_prev`, `funcs`, `salt`, `fields_type`, `fields_null`, `fields_null_prev`, `auto_increment`, `virtual` under `[multi_edit][row]`. Iteration follows `fields_name` order ("to avoid problems when inserting multiple entries"). For each field:
- Missing value (nullified select) → `''`; array value (SET) → `implode(',')`.
- `File::checkTblChangeForm(key,row)` checks `$_FILES['fields_upload']` then `fields_uploadlocal` (only when `UploadDir` set; rejects symlinks "File is a symbolic link", unreadable "File could not be read!"); PHP upload errors produce the standard messages ("The uploaded file exceeds the upload_max_filesize directive in php.ini.", "...MAX_FILE_SIZE...", "only partially uploaded", "Missing a temporary folder.", "Failed to write file to disk.", "File upload stopped by extension.", "Unknown error in file upload."). Uploaded content becomes `0x<hex>` and `isUploaded=true` (used verbatim in SQL).
- Input transformation: if `column_info` has `input_transformation`, `applyTransformation(value, options)` is applied; `isSuccess()===false` marks `insertFail`, `rowSkipped`, and collects "Row: %1$s, Column: %2$s, Error: %3$s". Such a row's columns still enter the INSERT column list while no row was added yet (so a failing first row followed by a good one produces a column list twice as long and the INSERT fails). Failed rows are stashed in `ChangeController::$unsavedValues[row]` so `/table/change` re-renders them with their typed values.
- `EditField(columnName, value, type, autoIncrement, isNull, wasPreviouslyNull, function, salt, previousValue, isUploaded)`.
- Virtual columns are skipped. **Insert**: if value equals the column default pulled by `getColumnDefaultValues()` (`INFORMATION_SCHEMA.COLUMNS`, quoting non-`DEFAULT_GENERATED` defaults) the raw value is used, else `getQueryValueForInsert()`; column names collected once from the first row that produced any value. **Update**: `getQueryValueForUpdate()` returns `` `col` = <sql> `` only if (was NULL and now not) or `isNull` or a function was applied or `value !== previousValue`; returns `''` when previously NULL and still NULL, or when the formatted value is `''` (untouched protected BLOB).

`getValueFormattedAsSql()`: uploaded → raw `0x…`; function set → `formatAsSqlFunction()`; else `formatAsSqlValueBasedOnType()`:
- `protected`: in UPDATE with key, the current value is re-read (`SELECT col FROM tbl WHERE clause LIMIT 1`) and emitted as `0x<hex>`; else `NULL` if the NULL box is checked; `''` (empty string literal) if it was NULL and is now unchecked; otherwise nothing (field omitted).
- `uuid` type: empty/`''`/`uuid()` → `uuid()`; `'uuid_v4()'`→`uuid_v4()`; `'uuid_v7()'`→`uuid_v7()`.
- Empty string → `NULL` if auto-increment or NULL checked, else `''`.
- `hex` → value prefixed with `0x` unless already.
- `bit` → non-`[01]` chars replaced by `0`, emitted as `b'0101'`.
- `datetime|timestamp|date` whose value matches `/^current_timestamp(\([0-6]?\))?$/i` → emitted unquoted.
- Otherwise `dbi->quoteString(value)` (single-quoted, escaped).

`formatAsSqlFunction()`: `PHP_PASSWORD_HASH` → PHP `password_hash(value, PASSWORD_DEFAULT)` quoted; `UUID` → `SELECT UUID()` executed first and the literal inserted ("This way user will know what UUID new row has"); GIS `*FromText`/`*FromWKB` → value parsed as `'wkt',srid` and emitted `FUNC('wkt',srid)`; `AES_ENCRYPT/AES_DECRYPT/SHA2` with salt (non-null) and `DES_ENCRYPT/DES_DECRYPT/ENCRYPT` with truthy salt → `FUNC('value','salt')`; `NOW` with numeric value 0..6 → `NOW(n)`; functions in `FUNC_NO_PARAM` (`CONNECTION_ID, CURRENT_USER, CURDATE, CURTIME, CURRENT_DATE, CURRENT_TIME, DATABASE, LAST_INSERT_ID, NOW, PI, RAND, SYSDATE, UNIX_TIMESTAMP, USER, UTC_DATE, UTC_TIME, UTC_TIMESTAMP, UUID, UUID_SHORT, UUID_v4, UUID_v7, VERSION`) → `FUNC()` unless value non-empty and function in `FUNC_OPTIONAL_PARAM` (`NOW, RAND, UNIX_TIMESTAMP`); everything else → `FUNC('value')`.

Query assembly: INSERT → `QueryGenerator::buildInsertSqlQuery()` = `INSERT [IGNORE ]INTO `tbl` (`c1`, `c2`) VALUES (v…), (v…)` — one statement for all rows. UPDATE → one statement per row: ``UPDATE `tbl` SET a = x, b = y WHERE <where_clause>[ LIMIT 1]`` (`LIMIT 1` appended unless `clause_is_unique` is truthy). No statements and no preview and no skipped row → message "No change" and return to caller (`/table/replace`→`/table/change` loop guard).

`preview_sql` → JSON `sql_data` and stop. Otherwise `executeSqlQuery()`: `Current::$sqlQuery = implode('; ', $query) . ';'`; for `submit_type=showinsert` nothing is executed and a notice "Showing SQL query" is added per statement; else each statement runs with `tryQuery` when `$cfg['IgnoreMultiSubmitErrors']` (default `false`) or `query` otherwise; affected rows summed; `insertId` (adjusted by affected-1 for multi-row inserts) → notice "Inserted row id: %1$d"; SQL warnings collected (`SHOW WARNINGS`). Result message: "%1$d row inserted."/"%1$d rows inserted." or "%1$d row affected."/"rows affected."; transformation errors, warnings and errors are appended and set the message type to Error; a skipped row forces return to `/table/change`.

Grid-edit branch (`isAjax && !ajax_page_request`): `doTransformations()` — parses `rel_fields_list` to recompute relational display links (`getDisplayValueForForeignTableColumn` runs `SELECT display FROM fdb.ftbl WHERE ffield='v' LIMIT 1`; `getLinkForRelationalDisplayField` builds `<a href="/sql?db&table&pos=0&sql_query=SELECT * FROM … WHERE ffield='v'" title=…>` showing key or display value per `$_SESSION['tmpval']['relational_display']` K/D), parses `transform_fields_list` and applies both input and output transformations to echo back the displayed value, calls `verifyWhetherValueCanBeTruncatedAndAppendExtraData()` (re-selects the saved column, returns `isNeedToRecheck` + `truncatableFieldValue` with microseconds padded / binary as `0x`), adds `row_count` and `sql_query` (message HTML), returns JSON. Otherwise, `after_insert=new_insert` unsets `where_clause` so the next `/table/change` renders blank insert rows, and control is dispatched in-process to `/sql`, `/database/sql`, `/table/sql` or `/table/change`.

**Config directives involved:** `InsertRows` (2), `ShowFunctionFields` (true), `ShowFieldTypesInDataEditView` (true), `CharEditing` ('input'), `MinSizeForInputField` (4), `MaxSizeForInputField` (60), `CharTextareaCols` (40), `CharTextareaRows` (7), `TextareaCols` (40), `TextareaRows` (15), `LongtextDoubleTextarea` (true), `TextareaAutoSelect` (false — listed in the Text_fields form but only affects the SQL query box, not this form), `ProtectBinary` ('blob'), `UploadDir` (''), `LimitChars` (50), `DefaultFunctions`, `IgnoreMultiSubmitErrors` (false), `ShowPropertyComments` (true), `ForeignKeyMaxLimit` (100), `ForeignKeyDropdownOrder` (['content-id','id-content']), `NaturalOrder` (true), `FirstDayOfCalendar` (0), `BrowseMIME` (true), `SaveCellsAtOnce` (false, grid), `GridEditing` ('double-click', grid), `RelationalDisplay` ('K').

**Related pmadb storage:** `pma__column_info` (`input_transformation`, `input_transformation_options`), `pma__relation` (internal relations for FK widgets), `pma__table_info.display_field` (display column), user preferences for the `Edit`/`Text_fields` setting groups.

### 3. Foreign-key value widgets (dropdown)

`Relation::getForeignData(foreigners, field, overrideTotal=false, filter='', limit='')` for the form:
- Finds the foreigner for the column (internal relation first, then native FOREIGN KEY; `searchColumnInForeigners`).
- `Table::checkIfMinRecordsExist(ForeignKeyMaxLimit)` runs `SELECT <unique cols | indexed cols | *> FROM ftable LIMIT <ForeignKeyMaxLimit>` and returns true if that many rows exist. If so (and not overridden) → `foreignLink=true`, no dropdown.
- Otherwise `getDisplayField(fdb, ftable)` (pmadb `pma__table_info.display_field`; emulated for `information_schema.CHARACTER_SETS`→`DESCRIPTION`, `TABLES`→`TABLE_COMMENT`; else the first CHAR-class column) and ``SELECT `ffield`[, `display`] FROM fdb.ftable [WHERE ffield LIKE '%f%' OR display LIKE '%f%'] [ORDER BY ftable.display] <limit>``. Empty result or no SELECT privilege → `foreignLink=true` (text box + browse icon).
- `Relation::foreignDropdown(dispRow, ffield, display, data, ForeignKeyMaxLimit)`: builds `$foreign[key]=display`. With a display field, two sections are produced using `$cfg['ForeignKeyDropdownOrder']` (default `['content-id','id-content']`): the first (`top`) and optional second (`bottom`). Without a display field a single `id-only` section. Output: leading `<option value="">&nbsp;</option>`; the top section only if `maxNumberOfItems === -1` or fewer than that many items, followed by another blank separator option when a display field exists; then the bottom section. `buildForeignDropdown(mode)`: `id-content`/`id-only` sorted by key (`uksort strnatcasecmp` when `NaturalOrder`, else `ksort`), `content-id` sorted by value (`natcasesort`/`asort`); invalid-UTF-8 or control-char keys/values are shown as `0x<hex>` (and selected-matching accounts for a `0x` prefix in `data`); values longer than `LimitChars` are truncated with `...`; option text is `value - key`, `key - value` or `key`.
- The hidden `fields_type` is `hex` for binary FK columns (so `0x…` keys are emitted raw) else `foreign` (quoted as a normal string).
- With a foreign field present the function dropdown has **no** preselected default (`getFunctionsForField(..., hasForeignField=true)`).

### 4. Browse foreign values popup (`/browse-foreigners`)

**Purpose.** Pick a key from the referenced table when the dropdown is not used (too many rows, or in grid editing). Opened by `a.browse_foreign` (insert form) and from the grid edit area (`makegrid.ts` `.browse_foreign` inside `.edit_area`).

Clicking `td a.foreign_value` puts `data-key` into the input preceding the link (or the grid `.edit_box`), triggers `change` (which unchecks NULL/Ignore through `verificationsAfterFieldChange`) and hides the modal. Submitting the inner form (`#browse_foreign_form`) is intercepted: if the filter text differs from `data-old` the page selector `select[name=pos]` is reset to 0; clicking `#foreign_showAll` sets a flag so the button's name/value is included; the POST response replaces the form and the table in place. **Layout.**

2. `<table class="table table-striped table-hover" id="browse_foreign_table">`; if no data: empty table. Else header (repeated in `<thead>`, `<tfoot>` and every `$cfg['RepeatCells']` (100) rows): **Keyname | Description | (20% spacer) | Description | Keyname**.
3. Rows (`getHtmlForOneKey`): the left pair lists entries **sorted by key** (`asort($keys)`), the right pair lists the same entries **in description order** (the query's `ORDER BY display`), so the two halves are two independently sorted views of the same page. Each cell is `column_element.twig`: `<a class="foreign_value" data-key="<key>" href="#" title="Use this value[: <full description>]">` showing the key (nowrap cells) or the description (truncated to `LimitChars` with `...`, full text in the title). The entry equal to the current `data` is wrapped in `<strong>`.

### 6. GIS data editor (`/gis-data-editor`, modal `#gisEditorModal`)

**Purpose.** Build a WKT literal (`'POINT(1 2)',4326`) for a geometry column with a form of coordinate inputs and a live SVG/OpenLayers preview; copy it into the row's text input.

**Opening (`change.ts`, `show.bs.modal` on `#gisEditorModal.editor-for-change`).** Reads from the clicked button's row: current value (the sibling text input), field name (first hidden `fields_name` input), column type (`span.column_type` text — so the Type column must be rendered; if `ShowFieldTypesInDataEditView` is off the type is empty and the editor falls back to detecting the type from the value or `POINT`), and the input `name`. `openGISEditor()` lazily loads `js/vendor/openlayers/openlayers.js` and `js/table/gis_visualization.js` (synchronously chained), then POSTs `field, value, type, input_name, ajax_request, server` to `/gis-data-editor`.

**Server (`GisDataEditorController`).** Requires `field`. `gis_data` (array) from POST, `type` (default `GEOMETRY`), `value`, `input_name`. `extractGisType()`: use `gis_data[gis_type]` if valid; else the uppercased column type; else, if the value matches `/^'?(\w+)\b/`, the WKT keyword; else `POINT`. `GisFactory::fromType()` instantiates the geometry class; if a `value` is given, `generateParams(value)` parses `'WKT',srid` or bare WKT (`parseWktAndSrid`) into nested `gis_data` arrays. Then `generateWkt(gisData, 0)` builds the WKT (`$result = "'" . $wkt . "'," . $srid`), and a second WKT with empty coordinates replaced by `0` feeds `GisVisualization::getByData([[wkt,srid]], GisVisualizationSettings(450,300,'wkt'))` → `asSVG()` and `asOl()` (`{geometries:[{wkt,srid?,label?}], colors}`). With `generate` posted → JSON `{result, visualization (svg), openLayersData}`; otherwise JSON `gis_editor` (rendered `gis_data_editor_form.twig`) and `gis_editor_title` = 'Value for the column "%s"'.

**Form layout (`gis_data_editor_form.twig`).** `<form id="gis_data_editor_form" action="/gis-data-editor" method="post" class="disableAjax">` with hidden `field`, `type` (uppercased column type), `input_name`, token. **Coordinate inputs (built client-side in `gis_data_editor.ts` from `data-gis-data`).**

Parsing (`getCoordinateParams`) is positional string slicing (`POINT(`=6 chars, `LINESTRING(`=11, `POLYGON((`=9, `MULTIPOLYGON(((`=15, `GEOMETRYCOLLECTION(`=19) and `explode` on `),(` / `)),((`.

### 7. Transformations — storage, configuration and dispatch

**Storage (`pma__column_info`, `resources/sql/create_tables.sql`):** columns `db_name, table_name, column_name, comment, mimetype, transformation, transformation_options, input_transformation, input_transformation_options` (all `varchar(255)`), unique on `(db_name, table_name, column_name)`. Requires the `browserTransformationFeature` (and for the Structure UI also `columnCommentsFeature`) of pmadb plus `$cfg['BrowseMIME']=true`.

**Structure UI (`columns_definitions/column_attributes.twig`, shown only when both features exist and `BrowseMIME`):** five extra per-column cells — **Media type** `<select name="field_mimetype[n]">` (options = every `mimetype` discovered, value with `/`→`_`, text lower-cased), **Browser display transformation** `<select name="field_transformation[n]">` (option value = plugin file path e.g. `Output/Text_Plain_Dateformat.php`, text = `getName() (text/plain: Dateformat)`, `title` = `getInfo()` description), **Transformation options** `<input type="text" name="field_transformation_options[n]" size=16>`, **Input transformation** `<select name="field_input_transformation[n]">`, **Input transformation options** text. Saved by `Structure/SaveController` and `AddFieldController` via `Transformations::setMime()` (mimetype and transformation lower-cased; existing row → UPDATE, or DELETE when all five values are empty and no comment; new → INSERT). `ColumnsDefinition` loads existing values with `getMime()`.

**Discovery (`Transformations::getAvailableMimeTypes`)** scans `src/Plugins/Transformations/Input/` (prefix `input_`), `Output/` and the root directory; a file named `A_B_C.php` yields MIME `A/B` and transformation name `A/B: C`; root-level plugins are registered as **both** output and input transformations; a file `A_B.php` is an "empty" MIME type with no function. The overview page `/transformation/overview` (`OverviewController`, `transformation_overview.twig`) lists "Available media types" (empty ones in italics), "Available browser display transformations" and "Available input transformations" with descriptions; menu and console are disabled on that page.

**Options parsing (`Transformations::getOptions`)** splits the options string on commas, honours single-quoted segments that may themselves contain commas, strips the quotes and backslashes (`stripslashes`). `TransformationsPlugin::getOptions($options, $defaults)` fills each default index from the parsed options when the option is non-empty, so defaults come from `$cfg['DefaultTransformations']` (`src/Config/Settings/Transformations.php`): `Substring=[0,'all','…']`, `Bool2Text=['T','F']`, `External=[0,'-f /dev/null -i -wrap -q',1,1]`, `PreApPend=['','']`, `Hex=['2']`, `DateFormat=[0,'','local']`, `Inline=['100',100]`, `TextImageLink=[null,100,50]`, `TextLink=[null,null,null]`.

**Browse-mode application (`Display/Results.php`).** `mediaTypeMap` is built per result set keyed `db.table.column` (`getMime(db, table, strict=false, fullName=true)`), with pseudo-entries for `information_schema`/`mysql` system columns. For a cell: when `BrowseMIME`, a `mimetype` and a `transformation` exist → plugin instantiated; `transformOptions` get `wrapper_link`/`wrapper_params` = `db, table, where_clause_sign, where_clause, transform_key[, sql_query]`; `applyTransformation(value, options, meta)` renders the cell; `applyTransformationNoWrap()` (true only for External when option 4 is 1/empty) switches the cell to `text-nowrap`; cells get class `<mime_type>` and `transformed`. Built-in syntax highlighting (`transformationInfo`) is applied to known system columns unless the session option `hide_transformation` is set. Grid editing echoes transformed values back through `ReplaceController::doTransformations()`.

**Wrapper (`/transformation/wrapper`, `WrapperController`).** Requires valid `db`/`table`; `where_clause` + `where_clause_sign` (HMAC) or none (`LIMIT 1`); reads the row, picks `transform_key`; content type from `ct` param, else the column's stored mimetype (`_`→`/`) plus any `; charset=` option; download name from `cn`; `resize=jpeg|png` with `newWidth`/`newHeight` (clamped 1..2000) produces an aspect-preserving thumbnail via GD (`ImageWrapper`), JPEG quality 75; HTML content types are `htmlspecialchars`-escaped.

**Input transformations on the form.** `IOTransformationsPlugin` adds `getInputHtml()`, `getScripts()`, `isSuccess()/getError()/reset()`. When configured, the plugin HTML *replaces* the default widget (see §1.1 step 1), its scripts are appended to the page, and on save `applyTransformation()` converts the posted value before SQL formatting (and may veto the row).

## Rebuild notes (modern SPA mapping)

**Routes (client).**
- `/db/:db/table/:table/insert` → Insert form (N blank rows, N from user pref `InsertRows`; `?rows=N` to override).
- `/db/:db/table/:table/edit?where[]=…&sig[]=…&unique=1&action=update|insert` → Edit/Copy form (multiple where clauses supported).
- Modal routes/components: `BrowseForeignersModal`, `GisEditorModal`, `PreviewSqlModal`.
- `/transformations` overview page (static catalog).

**API endpoints (server).**
- `GET /api/tables/:db/:table/edit-form?where[]…` → `{ columns:[{name, type, trueType, displayType, typeClass, isNull, key, default, extra, length, specInBrackets, enumSetValues, fsp, isChar, isBinary, isBlob, comment, foreign:{mode:'none'|'dropdown'|'link', options?, displayField}, inputTransformation?:{plugin, options}, widget: 'text'|'textarea'|'enum-radio'|'enum-select'|'set'|'hex-input'|'hex-textarea'|'protected'|'foreign-link'|'foreign-select'|'gis'|'transformed', nullifyCode}], rows:[{values:{col:{value, isNull, hexValue?}}, whereClause, backupValues}], functions:{all:[...], defaultsByColumn:{...}}, flags:{uploadEnabled, hasBlob, uploadDirFiles, foundUniqueKey, isNumericWhere, showFunctionFields, showFieldTypes}, insertRows }` — one call replaces `ChangeController` + `InsertEdit::getHtmlForInsertEditRow`.
- `POST /api/tables/:db/:table/rows` body `{ mode:'insert'|'insertignore'|'update'|'showinsert', preview:bool, rows:[{ignore, whereClause, fields:{col:{value|null, function, salt, type, wasNull, prev, upload?}}}], afterInsert, clauseIsUnique }` → `{ statements:[…], executed:bool, affected, insertId, messages, warnings, errors, failedRows:[{index, errors, values}], next:{action, whereClause?} }` — mirrors `ReplaceController` + `InsertEdit::getQueryValueFor*`. Keep the exact value-formatting rules (hex `0x`, `b'…'`, `CURRENT_TIMESTAMP` passthrough, uuid helpers, function wrapping, GIS `'WKT',srid`).
- `POST /api/tables/:db/:table/rows/upload` (multipart) for BLOB files; or stream the file in the same multipart request keyed `rows[i].fields[col].upload`.
- `GET /api/tables/:db/:table/foreign/:column?filter=&page=&showAll=` → `{ total, pageSize, items:[{key, description}], keysSorted:[idx], descSorted:[idx] }` — both orderings derived client-side, replacing `BrowseForeigners`.
- `POST /api/gis/wkt` body `{ type, srid, gisData }` → `{ wkt, result:"'WKT',srid", svg, olGeometries }`; `POST /api/gis/parse` body `{ value, columnType }` → `{ gisType, srid, gisData }` (the `generateParams`/`extractGisType` logic).
- `GET /api/tables/:db/:table/cell?column&where&sig` → raw bytes (replaces `/table/get-field` and `/transformation/wrapper`, with `?resize=jpeg&w=&h=` and `?ct=&cn=`).
- `GET /api/transformations` → plugin catalog (name, mime, direction, option schema with defaults, description); `GET/PUT /api/tables/:db/:table/columns/:col/mime` → `{mimetype, transformation, transformationOptions, inputTransformation, inputTransformationOptions}` backed by `pma__column_info` semantics (delete row when all empty).

**Components.**
- `InsertEditPage` (state: rows[], columns[], flags, submitType, afterInsert, dirty flag for leave-guard), `RowTable` (per row; `IgnoreCheckbox` when index>0 in insert mode), `ColumnRow` → `FunctionSelect` (+ `SaltInput`, `HexNote`), `NullCheckbox`, `ValueWidget` dispatcher (`TextInput`, `CharTextarea`, `NumberInput` with min/max/inputmode, `DateTimeInput` with picker and fsp, `EnumRadios`/`EnumSelect` (20-char rule), `SetMultiSelect`, `HexInput`/`HexTextarea`, `ProtectedBinary`, `BlobUpload` (+ `UploadDirSelect`), `ForeignSelect`, `ForeignLinkInput` (+ browse button), `GisInput` (+ edit button), `TransformedInput` registry keyed by plugin name), `ActionsPanel`, `ContinueInsertion` (client-side row count), `ShowHideTypeFunctionToggles`.
- `BrowseForeignersModal`: search, pager, show-all (gated by `ShowAll`), two-sided table, bold current, click-to-fill.
- `GisEditorModal`: `GeometryTypeSelect` (GEOMETRY only), `SridInput`, recursive `GeometryInputs` (Point/MultiPoint/LineString/MultiLineString/Polygon/MultiPolygon/GeometryCollection with min-point rules and add buttons), `GisPreview` (SVG vs OpenLayers toggle), `OutputTextarea`, Copy/Cancel.
- `PreviewSqlModal` with SQL highlighting.
- Transformation renderers for Browse: one component per output plugin in the catalog table; transformation input widgets: `ImageUploadInput` (with FileReader preview), `FileUploadInput`, `IpInput` (binary/long), `CodeEditorInput` (json/sql/xml modes), plus pass-through plugins (Link, Longtoipv4, PreApPend, Substring, RegexValidation) that only affect the save pipeline.
- `ColumnMimeSettings` in the Structure column editor (five controls).

**State & behaviours to port.** Dirty tracking per field (`fields_prev` equivalent) to compute minimal UPDATE SETs; NULL tri-state (`wasNull`, `isNull`); per-row Ignore; function selection removing validation and min/max; keyboard grid navigation (Ctrl+arrows) over a `field[row][col]` focus matrix; leave-page guard; `after_insert` flow (reopen blank/same/next; "next" requires numeric unique where clause and server-side lookup); `edit_next` can be implemented statelessly by returning `next.whereClause` from the save response instead of session storage; signed where clauses can be replaced by server-issued opaque row tokens as long as the UI still exposes the human-readable clause for the "Edit next row" numeric check; user preferences for `Edit`/`Text_fields` groups must be editable inline (page-settings gear) and persist like `InsertRows` overrides.
