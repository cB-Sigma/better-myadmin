### Page skeleton (`resources/templates/base.twig`)

Every full (non-AJAX) page is rendered by `ResponseRenderer::getDisplay()` → `base.twig` with the data array produced by `Header::getDisplay()` and `Footer::getDisplay()`:

1. `<html lang="{lang}" dir="{ltr|rtl}" data-bs-theme="{theme_color_mode}">` — Bootstrap 5 colour mode attribute carries the theme's colour mode.
2. `<head>`: `viewport`, `referrer=same-origin`, `robots=noindex,nofollow,notranslate`, `google=notranslate`; inline `<script>window.allowThirdPartyFraming = "sameorigin"|1|0</script>`; when framing is **not** allowed an inline `<style id="cfs-style">html{display:none;}</style>` is emitted (removed later by `cross_framing_protection.ts` only when the page is top-level); favicon; `{theme_path}/jquery/jquery-ui.css`; CodeMirror CSS when `$cfg['CodemirrorEnable']` (default `true`) plus lint CSS when `$cfg['LintEnable']` (default `true`); theme CSS `{theme_path}/css/theme.css` or `theme.rtl.css` with `?v={version}`; `<title>`; the script tags (see Scripts below); `<noscript><style>html{display:block}</style></noscript>`.
3. `<body id="{body_id}">` (controllers may call `Header::setBodyId`).
4. `{{ header.navigation }}` — the whole left panel (only when `isMenuEnabled() && server > 0`).
5. `{{ header.custom_header }}` — `config/config.header.inc.php` rendered via `Generator::renderCustom(CUSTOM_HEADER_FILE, 'pma_header')`.
6. `{{ header.load_user_preferences }}` — when the preference storage type is `session` and `$_SESSION['userprefs_autoload']` is unset, `UserPreferences::autoloadGetHeader()` renders the "load preferences from browser localStorage" offer.
7. `<span id="no_hint" class="hide">` when `$cfg['ShowHint']` (default `true`) is false (JS checks for this to skip tooltips).
8. `<noscript>` error "Javascript must be enabled past this point!" unless `Header::disableWarnings()` was called.
9. When menu enabled and `server > 0`: `{{ header.menu }}` (breadcrumb + tabs, see Top bar) then `#page_nav_icons` (right-aligned row): the **user account dropdown** (`#userAccountDropdown`, button with `user` icon titled "Open user account menu") containing: current `user@host` linking to `/server/privileges?username=&hostname=`; divider; "phpMyAdmin documentation" (`b_docs`, docs link `index`); "MySQL documentation"/"MariaDB documentation" (`b_sqlhelp`); divider; **Appearance** colour-mode `<select id="themeColorModeToggle" name="themeColorMode">` inside a POST form to `/themes/set` with hidden `set_theme={theme_id}` — only when the theme declares more than one colour mode; labels "Light"/"Dark" or the mode name title-cased; "Settings" (`s_cog`, `/preferences/manage`); divider; "Log out" (`s_loggoff`, `/logout`). Next column: `<span id="lock_page_icon">` (filled by `ajax.ts` lock indicator), `<span id="page_settings_icon">` with `s_cog` image titled "Page-related settings", and `<a id="goto_pagetop" href="#">` with `s_top` image titled "Click on the bar to scroll to top of page".
10. `{{ header.console }}` — the console HTML (see Console).
11. `<div id="page_content">` containing `{{ header.messages }}` (a `Current::$message` or a `?message=` GET/POST param rendered as a notice), and when logged in the shared modals `modals/preview_sql_modal.twig`, `modals/enum_set_editor.twig`, `modals/create_view.twig`, then the controller output.
12. Footer (unless minimal): `#selflink` → `<a href="{self_url}" title="Open new phpMyAdmin window" target="_blank" rel="noopener noreferrer">` showing the `window-new` icon when `TabsMode` shows icons, otherwise the text "Open new phpMyAdmin window". `Footer::getSelfUrl()` builds `index.php?route=…&db=…&table=…&server=…[&single_table=…]`. Then `<div id="pma_errors">` with `ErrorHandler::getDispErrors()`, the footer scripts, the demo-server notice (`$cfg['DBG']['demo']`: "phpMyAdmin Demo Server:" + "Currently running Git revision %1$s from the %2$s branch." or "Git information missing!"), and `config/config.footer.inc.php` via `renderCustom(CUSTOM_FOOTER_FILE,'pma_footer')`.

`ResponseRenderer::setMinimalFooter()` (called by `ResponseRendererLoading` middleware when no server is selected, and by the login page) suppresses item 12 entirely; `Header::disableMenuAndConsole()` suppresses 4, 9, 10.

### Scripts emitted by `Header::getScripts()` (order matters)

`runtime.js`, `vendor/jquery/jquery.min.js`, `jquery-migrate.min.js`, `jquery-ui.min.js`, `vendor/bootstrap/bootstrap.js`, `vendor/js.cookie.min.js`, `vendor/jquery/jquery.validate.min.js`, `jquery-ui-timepicker-addon.min.js`, `index.php?route=/messages&l={lang}` (the translated `window.Messages` object, see JavaScriptMessagesController), `shared.js`, `menu_resizer.js`, `main.js`, then inline code `window.Navigation.update(window.CommonParams.setAll({...}))`. `Header::getDisplay()` conditionally adds: CodeMirror (`lib/codemirror.js`, `mode/sql/sql.js`, `addon/runmode/runmode.js`, `addon/hint/show-hint.js`, `addon/hint/sql-hint.js`; lint `addon/lint/lint.js` + `codemirror/addon/lint/sql-lint.js`) only when `CodemirrorEnable` **and** the request has a `User-Agent` (#20159); `vendor/tracekit.js` + `error_report.js` when `$cfg['SendErrorReports'] !== 'never'`; `drag_drop_import.js` when `$cfg['enable_drag_drop_import']` (default `true`); `shortcuts_handler.js` unless `$cfg['DisableShortcutKeys']` (default `false`); inline `javascript/variables.twig` (`firstDayOfCalendar`, `themeImagePath`, `mysqlDocTemplate`, `maxInputVars`); inline `ConsoleEnterExecutes=true|false`; the console's scripts (`console.js`); finally `datetimepicker.js` and `validator-messages.js`. `Scripts::addFile` de-duplicates by md5(filename); every file whose name does not contain `vendor`, `runtime.js`, `index.php`, `shared.js`, `datetimepicker.js`, `validator-messages.js` is flagged `has_onload` and `scripts.twig` emits `window.AJAX.scriptHandler.add('<file>', true|false)` for each plus `$(function(){ window.AJAX.fireOnload('<file>') })` for the onload ones. Script URLs are `js/<file>?v=<version>` (or `get_common(params + v)` for `index.php?…` entries). `Scripts::getFiles()` (used for the AJAX `scripts` JSON key) omits any filename containing `?`.

### `window.CommonParams` keys (`Header::getJsParams()`)

`common_query` (raw `Url::getCommonRaw([], '')`, no separator), `opendb_url` (route of `DefaultTabDatabase`), `lang`, `server`, `table`, `db`, `token` (`Session::getToken()`), `text_dir` (`ltr|rtl`), `LimitChars` (`$cfg['LimitChars']` default 50), `pftext` (`$_SESSION['tmpval']['pftext']`), `confirm` (`$cfg['Confirm']` default `true`), `LoginCookieValidity` (default 1440), `session_gc_maxlifetime` (php ini), `logged_in` (`dbi->isConnected()`), `is_https`, `rootPath`, `arg_separator` (`Url::getArgSeparator()`), `version`; plus when a server is selected `auth_type` and `user`.

### HTTP response headers (`Header::getHttpHeaders()`)

`Referrer-Policy: same-origin`; `Content-Security-Policy` (see Security); `X-XSS-Protection: 1; mode=block`; `X-Content-Type-Options: nosniff`; `X-Permitted-Cross-Domain-Policies: none`; `X-Robots-Tag: noindex, nofollow`; `Permissions-Policy: fullscreen=(self), interest-cohort=()`; `Core::getNoCacheHeaders()` → `Expires: <now GMT>`, `Cache-Control: no-store, no-cache, must-revalidate, pre-check=0, post-check=0, max-age=0`, `Pragma: no-cache`, `Last-Modified: <now>`; `Content-Type: text/html; charset=utf-8` unless the response is a transformation wrapper. The page `<title>` comes from `Header::getPageTitle()`: when `server > 0` it expands `$cfg['TitleTable']` (default `'@HTTP_HOST@ / @VSERVER@ / @DATABASE@ / @TABLE@ | @PHPMYADMIN@'`), `TitleDatabase` (`'@HTTP_HOST@ / @VSERVER@ / @DATABASE@ | @PHPMYADMIN@'`), `TitleServer` (`'@HTTP_HOST@ / @VSERVER@ | @PHPMYADMIN@'`) or `TitleDefault` (`'@HTTP_HOST@ | @PHPMYADMIN@'`) via `Util::expandUserString`; otherwise the literal `phpMyAdmin`.

**Interactions & edge cases (panel):**

- *Resizer* (`Navigation.ResizeHandler`): `mousedown` on `#pma_navigation_resizer` starts a drag; `mousemove` calls `setWidth(pos)` where `pos` is clamped to `[0, windowWidth-100]`; `mouseup` posts the new width to `/navigation/update-width` (`UpdateNavWidthConfigController`: non-numeric or negative → error "Unexpected parameter value."; else `UserPreferencesHandler::setUserValue('NavigationWidth')` + `updateConfigValue`) and triggers `$('#topmenu').menuResizer('resize')`. RTL support: uses `margin-right`/`right` when `<html dir="rtl">`.
- *Collapser* (`#pma_navigation_collapser`): click toggles between 0 and the previous width (defaults to 240 when both are 0); the arrow glyph is `&larr;` when open / `&rarr;` when collapsed (mirrored in RTL); title `Messages.strHidePanel` / `strShowPanel`. The collapsed width is also persisted via `/navigation/update-width`.
- `setWidth()` also sets `body margin-left`, positions `#floating_menubar` (moves `#server-breadcrumb` and `#topmenucontainer` into it, pads `body` by the menubar height, observes it with a `MutationObserver`), offsets `#pma_console` and `#pma_navigation_resizer`. Below 768px window width the panel takes the full window width, resizer width is 0, and the panel is initially hidden (`treeInit`: `isLoadedOnMobile → setWidth(0)`).
- `treeResize` recomputes tree height (`nav height − header height`, min 50 else 800) on `window.resize` and every 2 s via `setInterval`, and sets `body margin-bottom` to the console height.
- *State persistence*: `treeStateUpdate()` stores `navTreePaths` (JSON of `traverseForPaths()`), `server` and `token` in `sessionStorage`. On every page load (`onloadNavigation`): if `navTreePaths` is undefined → `Navigation.reload()`; else if stored `server`/`token` match CommonParams → `Navigation.reload(filterStateRestore, JSON.parse(navTreePaths))` restoring every expanded branch without animation; otherwise (different user) → `treeStateUpdate(); reload()`. Submitting any `form.config-form` (preferences) clears `navTreePaths`. Fast-filter texts are stored in `sessionStorage.navTreeSearchFilters` keyed `dbFilter` or by the branch `aPath`.
- *Drag & drop import*: when `$cfg['enable_drag_drop_import']` (`true`) a full-window `.pma_drop_handler` overlay "Drop files here" and a `.pma_sql_import_status` box ("SQL upload ( N ) x -") are present; `drag_drop_import.ts` uploads dropped `.sql`/`.sql.gz`/… files via the import route with progress bars (details belong to the Import area).

**Server-side behaviour.** `Navigation::getDisplay()` chooses: full page or `POST full=1` / `reload=1` → `NavigationTree::renderState()` (whole tree) — or legacy `renderDbSelect()` when `$cfg['ShowDatabasesNavigationAsTree']` (`true`) is false; any other AJAX request → `renderPath()` (one branch). On failure the template prints the error "An error has occurred while loading the navigation display".

**Config directives.** `NavigationDisplayLogo=true`, `NavigationLogoLink='index.php'`, `NavigationLogoLinkWindow='main'` (`'main'|'new'`), `NavigationDisplayServers=true`, `DisplayServersList=false`, `NavigationWidth=240` (0 = collapsed), `NavigationLinkWithMainPanel=true`, `NavigationTreePointerEnable=true`, `NavigationTreeAutoexpandSingleDb=true`, `ShowDatabasesNavigationAsTree=true`, `enable_drag_drop_import=true`.

**Database list fetching & pagination** (`Node::getData/getPresence`): three strategies depending on `$cfg['Servers'][$i]['DisableIS']` and whether the user has restricted database privileges (`UserPrivileges::databasesToTest`): (a) `INFORMATION_SCHEMA.SCHEMATA` with `LIMIT pos, FirstLevelNavigationItems`; (b) `SHOW DATABASES` + `array_slice`; (c) `SHOW DATABASES LIKE '<pattern>'` per testable database / `only_db` entry. All honour `hide_db` (regex, `NOT REGEXP`) and `only_db` (`LIKE` OR-list; a string is coerced to a one-element array). When grouping is enabled the pagination counts **first-level prefixes** (`SUBSTRING_INDEX(SCHEMA_NAME, sep, 1)`) instead of databases, so a page may hold more than `FirstLevelNavigationItems` databases. The initial page position when a database is selected is computed by `NavigationTree::getNavigationDbPos()` (number of distinct prefixes before the current db, floored to a page). A fast-filter search clause is applied as `LIKE '%clause%'` to `SCHEMA_NAME`/`Database`.

**Grouping algorithm** (`NavigationTree::groupTree/groupNode`, only when `NavigationTreeEnableExpansion`): for a container node with `separatorDepth > 0`, for every child find the **earliest** separator occurrence (not at position 0 or end) among `node->separators`; count prefixes; a prefix with only one member is not a group; a prefix that equals an existing child name is counted as well (Bug #4375) so `foo` and `foo_bar` group together (the Bug #4375 increment runs inside the per-child loop, so such a prefix's count is inflated; and because PHP turns a numeric prefix into an int array key, a sibling named exactly like a numeric prefix — `2024` next to `2024_a` — is *not* moved into the group); rfe #1634: if there is exactly one group and it contains all other items, do not group. Groups with > 500 members raise the user warning "There are large item groups in navigation panel which may affect the performance. Consider disabling item grouping in the navigation panel." (once). Group children are *cloned* nodes with the prefix stripped from `name` but `realName` kept, so links stay correct. If the current node is a plain `Node` group and the new group would contain all children, the two are merged (`node->name .= sep . prefix`, depth decremented) instead of nesting. For databases: `NodeDatabaseContainer` sets `separators=[NavigationTreeDbSeparator]` (`'_'`), depth 10000 (unlimited) when `NavigationTreeEnableGrouping` (`true`) and the tree mode is on. For tables/views/routines/events: `NodeDatabaseChildContainer` uses `NavigationTreeTableSeparator` (`'__'`; may be a string, an array of strings, or `false` to disable) with `separatorDepth = NavigationTreeTableLevel` (`1`).

**Sorting**: `sortNode()` — `isNew` first, then `strnatcasecmp` when `$cfg['NaturalOrder']` (`true`) else `strcasecmp`.

**Config directives.** `FirstLevelNavigationItems=100`, `MaxNavigationItems=50`, `NavigationTreeEnableGrouping=true`, `NavigationTreeDbSeparator='_'`, `NavigationTreeTableSeparator='__'`, `NavigationTreeTableLevel=1`, `NavigationTreeEnableExpansion=true`, `NavigationTreeDisplayDbFilterMinimum=30`, `NavigationTreeDisplayItemFilterMinimum=30`, `ShowCreateDb=true`, `NaturalOrder=true`, `Servers[$i]['hide_db']=''`, `Servers[$i]['only_db']=''`, `Servers[$i]['DisableIS']=false`.

### AJAX page-loading model (`modules/ajax.ts`, `ResponseRenderer::ajaxResponse`)

**Link/form interception.** `main.ts` delegates `click a` and `submit form` to `AJAX.requestHandler`. Native behaviour is kept when: Shift/Ctrl/Meta is held; the element has a `target` attribute; it has class `ajax` (handled by a feature script) or `disableAjax` (both also `resetLock()`); the href starts with `#` or `mailto`; or it is a datepicker arrow. Otherwise the handler `preventDefault()`s and: (1) if `lockedTargets` is non-empty and the click is real, asks `confirm(Messages.strConfirmNavigation)` "You have unsaved changes; are you sure you want to leave this page?"; (2) if a request is `active`, aborts the in-flight link `xhr` and shows "Request aborted!!" (`strAbortedRequest`) — form posts in progress cannot be aborted and the new click is ignored; (3) scrolls to top; (4) builds params `ajax_request=true&ajax_page_request=true` + form serialization (forms) or the link's `data-post` (links become POSTs); (5) shows the "Loading…" box (`ajaxShowMessage()`), issues `$.get` (links) or `$.post` (forms; `login_form` uses `loginResponseHandler`), and `history.pushState({url}, null, href)` (or `replaceState` if the previous link was aborted). Forms with an inline `onsubmit` have it removed on load (`removeSubmitEvents`, bug #3583316) and stored in jQuery data; it is evaluated before the AJAX submit and may veto it. Clicking a submit button adds a hidden input with its name/value so the serialized form carries the clicked button.

**Response contract** (success branch of `ResponseRenderer::ajaxResponse()`): `success:true`, `message` (HTML, or a rendered `Message`), `title` (`<title>…</title>`), `menu` (when connected), `scripts` (`[{name, fire}]`), `selflink`, `displayMessage`, `debug` (unless `no_debug`), `errors` (PHP error HTML), `promptPhpErrors`, `reloadQuerywindow {db, table, sql_query}`, `reloadNavigation: 1` when `ResponseRenderer::$reload`, `params` (= `getJsParams()`, see CommonParams). Failure: `success:false`, `error` (the message), optional `redirect_flag:'1'` (session expired → login), `reload_flag:'1'`, `fieldWithError`, `errSubmitMsg`, `sendErrorAlways`, `stopErrorReportLoop`, `isErrorResponse`, `redirect`, `disableNaviSettings`, `new_token`, `logged_in`. JSON encode failure → `{success:false, error:'JSON encoding failed: …'}`. Keys `menuHash`, `console_message_*` (other than `console_message_id` echoed by `/import`) and `_HTML` do **not** exist (*not found*).

**`responseHandler(data)`** — the page swap: a *string* response (non-JSON) is shown as a sticky error with its text. On success: scroll top, remove loading box; `data.redirect` → show it and stop; `scriptHandler.reset()` fires every registered teardown and re-binds the delegated handlers; then in order: `reloadNavigation` → `Navigation.reload()`; replace `<title>`; `menu` → `history.replaceState({url: selflink, menu})` + `handleMenu.replace()`; `disableNaviSettings ? Navigation.disableSettings() : Navigation.ensureSettings(selflink)`; remove every `body` child except `div.modal, #pma_navigation, #floating_menubar, #page_nav_icons, #page_content, #selflink, #pma_header, #pma_footer, #pma_demo, #pma_console_container, #prefs_autoload`; replace `#page_content` with `message`, `highlightSql()`, `checkNumberOfFields()`; set `#selflink a[href]` (remapping `/import`→`/table/sql`, `/table/chart`→`/sql`, `/table/gis-visualization`→`/sql`); `Navigation.update(CommonParams.setAll(params))` (re-syncs the tree when db/table changed); `scriptHandler.load(scripts)`; prepend `displayMessage`; rebuild `#pma_errors` after `#selflink` from `errors`, binding the "ignore" links (`#pma_ignore_errors_bottom`, `#pma_ignore_all_errors_bottom`, popup variants); if `sendErrorAlways==='1' && stopErrorReportLoop!=='1'` auto-submit `#pma_report_errors_form` and show `Messages.phpErrorsBeingSubmitted`; else if `promptPhpErrors` append `Messages.phpErrorsFound`; show `errSubmitMsg` sticky; run the one-shot `AJAX.callback`. On failure: `ajaxShowMessage(error, false)`, append `<div id="ajaxError">` to `#page_content`, scroll to bottom, `handleRedirectAndReload(data)` (`redirect_flag` → reload with `session_expired=1`; `reload_flag` → `location.reload()`), mark `#<fieldWithError>` with class `error`.

**Scripts** (`AJAX.scriptHandler`): tracks downloaded scripts by name; `load(files)` forgets everything when `CommonParams.version` changed, appends `<script src="js/<name>?v=<version>" async=false>` for new ones, fires `onload_<hash(name)>` events (`AJAX.registerOnload(file, fn)` / `registerTeardown`) once all are loaded, and sets `AJAX.active=false`. Known quirk: `done()` uses `$.inArray(...)` truthiness so the script at index 0 never gets its onload fired via that path.

**History / back.** `loadEventHandler` snapshots `{url: selflink, menu}` with `replaceState` on DOM ready; `popstate` (ignoring the initial one) shows "Loading…" and re-fetches `state.url || location.href` with `ajax_request=true&ajax_page_request=true` through `responseHandler`. No hash-based routing exists.

**Fatal AJAX errors** (`getFatalErrorHandler`, bound to global `ajaxError`): ignores `/git-revision`, `/console/update-config` and aborted requests; `responseJSON.isErrorResponse` → shows its `error`; otherwise sticky error "Error in processing request" + "Error code: %s" (HTTP status) + "Error text: %s" (statusText/state) + when state is `rejected`/`timeout` "It seems that the connection to server has been lost. Please check your network connectivity and server status.". No specific 401/"Token mismatch" branch exists in JS; the server's "Error: Token mismatch" (`TokenRequestParamChecking`) arrives as a normal `error`.

**Lock page (unsaved changes).** Forms with class `lock-page` get every field indexed (`data-lock-id`, `data-val-hash`) on load; `keyup/change` → `lockPageHandler` compares hashes (`value:1` text, `2` checkbox, `3` CodeMirror `isClean()`), fills `lockedTargets`, and shows `s_lock` in `#lock_page_icon` with tooltip `strLockToolTip` "Indicates that you have made changes to this page; you will be prompted for confirmation before abandoning changes". `reset` or navigation clears it.

**Idle/session expiry** (`functions.ts onloadIdleEvent`): when `logged_in`, after `min(LoginCookieValidity, session_gc_maxlifetime) − 5` seconds of inactivity POSTs `index.php?route=/` with `check_timeout=1, access_time, guid, db, server`; failure disables all `fieldset`s (`disabled_for_expiration`) and injects `data.error` (a login form inside `#modalOverlay`, `login/header.twig`); `loginResponseHandler` then updates `CommonParams.token`, replaces `input[name=token]`, re-enables fieldsets and refires `main.js` onload; a different user → full `window.location='index.php'`.

**Other cross-cutting JS.** `$.ajaxPrefilter(addNoCacheToAjaxRequests)` appends `_nocache=<time><rand>` and `token=<CommonParams.token>` to every jQuery AJAX request. `checkNumberOfFields()` warns "Warning: a form on this page has more than %d fields. On submission, some of the fields might be ignored, due to PHP's max_input_vars configuration." `refreshMainContent(url)` re-navigates via a synthetic link click. `highlightSql($base)` (`modules/sql-highlight.ts`) runs CodeMirror `runMode` over every visible `code.sql`, hides the `<code>` and links keywords/builtins to the MySQL docs (`<a target="mysql_doc" class="cm-sql-doc" href=sprintf(mysqlDocTemplate, page)#anchor>`). `updateCode()` highlights `code.json|sql|xml`. `slidingMessage(msg)` animates a `#PMA_slidingMessage` reveal at the top of `#page_content`.

**Cookie authentication flow** (`AuthenticationCookie.php`):
- Cookie names via `Config::getCookieName()`: `pmaUser-<server>`, `pmaAuth-<server>`, session `phpMyAdmin`, `pma_lang`, `pma_theme`; on HTTPS they become `__Secure-<name>_https`. `Config::setCookie()` flags: path `getRootPath()`, `secure=isHttps()`, `httponly=true`, `samesite=$cfg['CookieSameSite']` (`'Strict'`; `Lax|Strict|None`), default lifetime 30 days (`expires=null`), 0 = session cookie; setting a value equal to the default or `''` removes the cookie.
- Encryption: libsodium `crypto_secretbox` (XSalsa20-Poly1305); payload = `base64(nonce24 ‖ ciphertext)`. Key: `$cfg['blowfish_secret']` when ≥ 32 bytes (truncated to 32), otherwise a per-session random key `$_SESSION['encryption_key']` (hence the home warnings). The **username cookie** uses the blowfish key, the **password cookie** always uses the session key.
- POST login: captcha → `Core::sanitizeMySQLUser()` → password-length check → arbitrary-server handling → `Session::secure()` (regenerate id, unset, new token).
- Cookie login: decrypt `pmaUser-N`; require non-empty `$_SESSION['browser_access_time']`; prune entries older than `time() − LoginCookieValidity` (`1440` s); if all expired → clear privilege caches and throw `no-activity`; decrypt `pmaAuth-N` → JSON `{password, server?}`.
- `rememberCredentials()`: store `pmaUser-N` (30 days) and `pmaAuth-N` (lifetime `$cfg['LoginCookieStore']` = `0` → session cookie) unless `change_pw`; for a `session_timedout` re-login return JSON `logged_in:1, success:1, new_token`; for a fresh POST login issue a **302 to `./index.php?route=/` + db/table** so the browser accepts the cookies; cookie logins continue in place.
- Activity tracking: `setSessionAccessTime()` stores `$_SESSION['browser_access_time'][guid] = time() − clamp(access_time, 0, validity+1)` from the keep-alive POST (`check_timeout=1`, `access_time`, `guid`).
- `showFailure()`: log, delete `pmaAuth-N`, set `connectionError`, `Cache-Control: no-store…`, re-render the form.
- `logOut()`: deletes `pmaAuth-N` for **all** servers when `LoginCookieDeleteAll` (`true`), else only the current one, then the base logout.
- `LoginCookieValidity` may be overridden by user preferences (`LoginCookieValiditySetting` middleware reads the cached user pref).

**HTTP auth** (`AuthenticationHttp.php`): reads `PHP_AUTH_USER|REMOTE_USER|REDIRECT_REMOTE_USER|AUTH_USER|HTTP_AUTHORIZATION|Authorization` (+ `PHP_AUTH_PW|REMOTE_PASSWORD|AUTH_PASSWORD`), decodes `Basic`, unsets `$_SERVER['PHP_AUTH_PW']`; `?old_usr=<user>` forces a re-prompt (logout emulation); `showLoginForm()` sends `WWW-Authenticate: Basic realm="<auth_http_realm | 'phpMyAdmin ' + verbose|host>"` with HTTP 401, title "Access denied!", `<h1>` "Welcome to %s", error "Wrong username/password. Access denied."; AJAX → `reload_flag:'1'`. Non-1045 DB errors render `error/generic`.

## Rebuild notes (modern SPA mapping)

**Shell.** Replace the Twig `base.twig` + jQuery `AJAX.responseHandler` page-swap with a real SPA shell: fixed header (breadcrumb + scope tabs + user menu + page-settings/lock/scroll-top icons), resizable/collapsible left navigation, docked console, routed main outlet. Keep the observable contract: route-driven tab sets (matrix above), title templates (`@HTTP_HOST@ / @VSERVER@ / @DATABASE@ / @TABLE@ | @PHPMYADMIN@`), the "Open new window" deep link (route+db+table+server), and `d-print-none` equivalents for printing. Model the JSON response keys (`message`, `title`, `menu`, `scripts`, `selflink`, `displayMessage`, `errors`, `promptPhpErrors`, `reloadQuerywindow`, `reloadNavigation`, `params`) as typed API responses: page data + a side-effects envelope (`reloadNavigation`, `currentQuery`, `flashMessages`, `serverErrors`, `token`).

**Navigation tree — instant via virtualization & prefetch.**
- Data: expose paginated, filterable endpoints per level — `GET /api/servers/:s/databases?pos&q` (prefix-grouped count semantics when grouping is on), `/databases/:db/objects/:type?pos&q`, `/tables/:t/columns|indexes|triggers?pos`. Return `{items, total, hidden}` so the client can render page selectors exactly like `Generator::getListNavigator` (page size 100 for first level, 50 below) and the "%s results found" count.
- Render the tree as a flat virtualized list (react-window/TanStack Virtual) of visible rows derived from an expansion map keyed by `aPath` (base64-joined real names) — this keeps thousands of databases/tables smooth while preserving `pos2/pos3` per branch. Keep `vPath` (display path incl. groups) separate so grouped nodes link to the right real objects.
